## 🇨🇳 中文

这是面向办公场景的非虚构长文档工作台，专治手册、白皮书、报告、培训材料、人物口述、家谱和资料型书稿这类大块头文本。支持新建、续写、组装、改写、扩写、精修、去 AI 味、质检和交付共九类操作，同一份稿子可以反复迭代到满意。它明确划定了适用边界：不碰小说、网文、剧本、诗歌、世界观设定和角色剧情创作，也不接短问答、翻译和代码任务。工作台有硬规则和文件契约兜底，保证多轮操作后文档结构不散、口径不乱。交付时按统一口径输出，拿到的就是能直接用的稿子。

### ✨ 能做什么

- 覆盖手册、白皮书、报告、培训材料、人物口述、家谱、资料型书稿等长文档
- 九类操作：新建、续写、组装、改写、扩写、精修、去 AI 味、质检、交付
- 先界定适用边界，不接小说、网文、剧本、诗歌、世界观与角色剧情创作
- 也明确不处理短问答、翻译与代码任务，避免误用
- 工作台硬规则 + 文件契约，多轮迭代后结构不散、口径统一
- 去 AI 味与质检分开执行，改完还能按统一口径交付

## 🇬🇧 English

A workbench for long non-fiction documents in office settings — manuals, whitepapers, reports, training material, oral histories, genealogies and reference manuscripts. It covers nine operations: new drafting, continuation, assembly, rewriting, expansion, polishing, a de-AI-flavor pass, quality checking and delivery, so one manuscript can be iterated until it's right. Its scope is stated up front: no novels, web fiction, scripts, poetry, worldbuilding or character/plot creation, and no short Q&A, translation or code work. Hard workbench rules and file contracts keep structure and terminology stable across many rounds. Delivery follows one consistent format, so what comes out is usable as-is.

### ✨ What it does

- Handles manuals, whitepapers, reports, training material, oral histories, genealogies and reference manuscripts
- Nine operations: new draft, continue, assemble, rewrite, expand, polish, de-AI pass, QC, deliver
- States its scope up front and excludes novels, web fiction, scripts, poetry and worldbuilding
- Also declines short Q&A, translation and code tasks to prevent misuse
- Hard workbench rules plus file contracts keep structure and wording stable across rounds
- De-AI polishing and quality checking run as separate passes, then delivery uses one format
